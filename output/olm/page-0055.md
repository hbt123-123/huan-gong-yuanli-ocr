假设完全混合,所以室内甲醛浓度与流出空气中的甲醛浓度相等,即输出速率为
\[
q_{m2} = (1000 \ \mathrm{m}^3/\mathrm{h}) \rho
\]
降解速率为
\[
k \rho V = (0.40 \times 500 \ \mathrm{m}^3/\mathrm{h}) \rho = (200 \ \mathrm{m}^3/\mathrm{h}) \rho
\]
因为
\[
q_{m1} - q_{m2} - k \rho V = 0
\]
即
\[
140 \ \mathrm{mg}/\mathrm{h} - (1000 \ \mathrm{m}^3/\mathrm{h}) \rho - (200 \ \mathrm{m}^3/\mathrm{h}) \rho = 0
\]
所以
\[
\rho = \frac{140}{1200} \ \mathrm{mg}/\mathrm{m}^3 = 0.117 \ \mathrm{mg}/\mathrm{m}^3
\]
甲醛的相对分子质量为 30,在 1.013 \times 10^5 \ \mathrm{Pa}、25 \ ^\circ\mathrm{C} 下,甲醛的体积分数为
\[
\frac{RT \times 10^3}{M_A \rho} = \frac{8.314 \times 298 \times 10^3}{30 \times 1.013 \times 10^5} \times 0.117 \times 10^{-6} = 0.095 \times 10^{-6} \quad \text{(体积分数)}
\]
办公室内甲醛含量接近引起眼刺激的起始浓度的两倍。

3. 非稳态系统
在非稳态系统中,物质的质量和浓度随时间变化,因此需要采用微分衡算式,通过在初始状态和最终状态之间积分求得未知量。

【例题 2.2.5】某圆筒形储罐直径为 0.8 m,罐内盛有 2 m深的水,在无水源补充的情况下,打开底部阀门放水,见图 2.2.8。已知水的密度为 1000 kg/m^3,水流出的质量流量 q_{m2} 与水深 z 的关系为
\[
q_{m2} = 0.274 \sqrt{z}
\]
求经过多长时间后,水位下降至 1 m?
解: 根据质量衡算方程,有
\[
q_{m1} - q_{m2} = \frac{dm}{dt}
\]
因为无水源补充,所以 q_{m1} = 0。
\[
q_{m2} = 0.274 \sqrt{z}
\]
储罐的横截面积为
\[
A = \frac{\pi}{4} d^2 = \frac{\pi}{4} 0.8^2 \ \mathrm{m}^2 = 0.502 \ \mathrm{m}^2
\]
